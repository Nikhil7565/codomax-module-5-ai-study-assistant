# 🤖 AI Study Assistant

An AI-powered study assistant built using Python, Streamlit, and Google Gemini as part of the **Codomax Digital Internship - Module 5**.

## 🚀 Features

- Ask questions about any study topic
- Get simple explanations
- Generate important key points
- Get short summaries
- Generate practice questions
- Interactive Streamlit interface
- Powered by Google Gemini

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini API
- Google GenAI Python SDK
